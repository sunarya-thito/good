# goo_net_steam

Steam backend for [`goo_net`](../goo_net): lobbies via `ISteamMatchmaking`,
P2P via `ISteamNetworkingSockets` (which also gives Valve's relay network as
a free fallback when direct P2P fails). Built on top of
[`goo_ffi_steamworks`](../goo_ffi_steamworks)'s raw bindings.

Status: **placeholder.** This is Phase 3 of the project root plan; nothing
here is implemented yet.
