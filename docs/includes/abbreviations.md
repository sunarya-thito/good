*[ECS]: Entity Component System — entities are ids, components are data, systems are the code that runs over them
*[EC]: Entity-component — one object per thing, with scripts attached to it. Unity, Godot and Flame work this way
*[cache line]: The block of memory a CPU actually fetches at once — typically 64 bytes
*[entity]: One thing in your game. Just a number that indexes its data
*[prefab]: A kind of entity, declared once — what fields it has and what it starts as
*[archetype]: The group entities with the same set of components are stored in
*[descriptor]: The object a describe* method fills in to declare something
*[isolate]: Dart's unit of parallelism. Separate memory, own event loop
*[tick]: One step of the simulation
*[hot path]: Code that runs every frame, where small costs multiply
*[collider]: The shape used to work out what a thing collides with
*[rigid body]: The thing physics moves, with mass and velocity
*[FFI]: Foreign Function Interface — calling C from Dart
*[PBR]: Physically Based Rendering — materials that respond to light realistically
*[glTF]: The standard file format for 3D models
*[AOT]: Ahead Of Time — compiled to machine code before running
*[JIT]: Just In Time — compiled while running
*[NAT]: Network Address Translation — what a home router does to your address
*[STUN]: A protocol for learning your own public address
*[UDP]: A network protocol that sends packets without guaranteeing delivery
